LIVELLO 2

⚙️ Intermediate: Specializzazione (3-6 mesi)

Scegli una specializzazione: diventa Blue Team (difesa) oppure Red Team (attacco). Impara gli strumenti reali e inizia con lab hands-on su TryHackMe.

🔴 Red Team: Attacco

Cosa imparare: Reconnaissance, scansione, exploit, social engineering.

  • → Cos'è il Pentesting

🔵 Blue Team: Difesa

Cosa imparare: Risk management, detection, incident response.

  • → Risk Management
  • → IAM e RBAC

  • Lab: TryHackMe "SOC Analyst" path

LIVELLO 3

🚀 Advanced: Professionista (6+ mesi)

Specializzazione profonda. Diventa esperto in una disciplina specifica: pentesting, forensica, malware analysis, threat intelligence, architecture. Tempo: 15-20 ore/settimana per mantenere competenza.

🔍 Malware Analysis

Reverse engineering, detonazione controllata, comportamento dinamico.

Richiede: Intermediate pentesting + assembler base

🕵️ Forensica Digitale

Analisi disco, memory dump, timeline reconstruction, evidence preservation.

Richiede: Blue team + nozioni OS Windows/Linux

🤖 Threat Intelligence

OSINT, APT hunting, threat modeling, vulnerability intelligence.

Richiede: Intermediate (red o blue) + ricerca

🏗️ Architecture & Cloud Security

AWS/Azure security, Kubernetes, zero trust, supply chain.

Richiede: Network + blue team + linux admin

🎓 Certificazioni consigliate: OSCP, CEH, GIAC (GCIH, GCIA), CISSP (dopo esperienza). Non sono obbligatorie ma riconosciute dal mercato.

📖 Glossario Rapido

APT (Advanced Persistent Threat)
Attaccante sofisticato (solitamente state-sponsored) che mira a rimanere nascosto per lungo tempo dentro un network. Differisce dal script kiddie per metodologia, pazienza e risorse.
Exploit
Codice o tecnica che sfrutta una vulnerabilità specifica per ottenere accesso non autorizzato o eseguire azioni non consentite.
Payload
Parte dell'exploit che esegue l'azione vera (es. reverse shell, file drop, credential dump). Il vettore è come arriva il payload, il payload è cosa fa.
Zero-Day
Vulnerabilità sconosciuta al fornitore (day-zero), non ancora patchata. Di massimo valore per attaccanti perché non esiste difesa nota.
Supply Chain Attack
Attacco non al target diretto, ma ai suoi fornitori/dipendenze. Es: hackerare la libreria che usa, il software update che distribuisce, la catena logistica.
OSINT (Open Source Intelligence)
Raccolta di informazioni da fonti pubbliche (internet, social, documenti). Fase 0 di qualunque attacco serio.
Privilege Escalation
Salire di privilegi da user verso admin/root. Fondamentale in pentesting: prima entri (magari come user), poi escalate per controllo totale.
Lateral Movement
Muoversi da un host compromesso ad altri host nella stessa rete. Tipico di attacchi mirati (APT).
Incident Response
Procedura organizzata per rispondere a un attacco: detect → contain → eradicate → recover → lessons learned.
